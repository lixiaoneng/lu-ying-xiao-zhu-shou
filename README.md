## 为什么做这个

组织过几次多家庭露营之后，我发现有一个问题始终没被解决好：**分工总是乱的**。

大家通常建一个腾讯文档，列谁带帐篷、谁买肉、谁负责炉子……然后在群里发来发去。有人没看到，有人重复买了，等到结束 AA 的时候谁也算不清楚。腾讯文档的手机端体验本来就一般，露营场景下更难用——光是在表格里找自己那一行就要滑半天。

于是我用 Claude Code 花了几天时间做了这个东西。没有大需求，就是把每次露营时真正用到的功能做进去。现在已经在真实的活动里跑起来了。

---

## 核心功能

| | 功能 | 说明 |
|---|------|------|
| 🎒 | 物资分工 | 各家自带、公共物资、食材采购，按家庭分配，一目了然 |
| ✅ | 备齐勾选 | 勾选「已备好」，实时同步给所有人，不用再群里 @ 确认 |
| ⚖️ | AA 计算 | 支持按家庭或按人头均摊，自动生成转账方案 |
| 🍽 | 菜单规划 | 安排每顿饭吃什么、谁负责做，和物资联动 |
| 📋 | 一键分享 | 生成可直接发到群里的文案，或截图分享 |
| 🔗 | 房间码协作 | 六位码加入，多设备实时同步 |

## 本地运行

```bash
git clone https://github.com/lixiaoneng/lu-ying-xiao-zhu-shou.git
cd lu-ying-xiao-zhu-shou
npm install
npm run dev
```

Supabase 是可选的。不配置也能正常用，数据存在本地，只是没有多设备同步。

需要实时协作功能的话，复制 `.env.local.example`，填入你自己的 Supabase 项目信息即可。
